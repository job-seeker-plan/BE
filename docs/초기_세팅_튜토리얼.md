# 초기 세팅 튜토리얼

이 프로젝트는 하나의 GitHub Organization 아래에서 `BE`, `AI`, `FE`, `DATA`를 독립 저장소로 운영합니다. 네 저장소를 같은 상위 폴더에 클론해야 Docker Compose가 AI 서비스를 내부망으로 연결할 수 있습니다.

## 1. 준비물

- Git
- Docker Desktop (Docker Compose 포함)
- Node.js 20 이상
- 선택: Python 3.12 이상, Maven 3.9 이상 — Docker를 사용하지 않고 각 서비스를 개별 실행할 때만 필요합니다.

## 2. 저장소 클론

```bash
mkdir job-seeker-plan
cd job-seeker-plan
git clone https://github.com/job-seeker-plan/BE.git BE
git clone https://github.com/job-seeker-plan/AI.git AI
git clone https://github.com/job-seeker-plan/FE.git FE
git clone https://github.com/job-seeker-plan/DATA.git Data
```

완료 후 구조는 아래와 같아야 합니다.

```text
job-seeker-plan/
├── AI/
├── BE/
├── Data/
└── FE/
```

## 3. 백엔드 환경변수 설정

```bash
cp BE/.env.example BE/.env
```

`BE/.env`에 아래 값을 설정합니다. 비밀 값은 절대 Git에 커밋하지 않습니다.

```dotenv
DATABASE_PASSWORD=로컬_데이터베이스_비밀번호
AI_SERVICE_TOKEN=충분히_긴_임의_문자열
GOV_API=발급받은_온통청년_API_키
FRONTEND_URL=http://localhost:5173
```

`AI_SERVICE_TOKEN`은 Spring Boot와 FastAPI가 동일한 값으로 사용하는 내부 통신용 키입니다. macOS/Linux에서는 다음으로 생성할 수 있습니다.

```bash
openssl rand -hex 32
```

## 4. OAuth 설정

Google, Kakao, Naver 중 사용할 제공자의 개발자 콘솔에 아래 Redirect URI를 등록하고, 같은 제공자의 client id와 secret을 `BE/.env`에 넣습니다.

```dotenv
OAUTH_GOOGLE_CLIENT_ID=
OAUTH_GOOGLE_CLIENT_SECRET=
OAUTH_KAKAO_CLIENT_ID=
OAUTH_KAKAO_CLIENT_SECRET=
OAUTH_NAVER_CLIENT_ID=
OAUTH_NAVER_CLIENT_SECRET=
```

```text
http://localhost:8000/login/oauth2/code/google
http://localhost:8000/login/oauth2/code/kakao
http://localhost:8000/login/oauth2/code/naver
```

설정하지 않은 제공자의 로그인 버튼은 비활성화됩니다. 최소 하나는 반드시 설정해야 로그인할 수 있습니다.

## 5. 백엔드·AI·DB 실행

상위 폴더 `job-seeker-plan/`에서 실행합니다.

```bash
docker compose -f BE/docker-compose.yml --env-file BE/.env up --build
```

브라우저는 `http://localhost:8000`의 Spring Boot API만 호출합니다. FastAPI AI는 Docker 내부 네트워크에서 Spring Boot만 접근할 수 있습니다.

중지할 때는 다음을 실행합니다.

```bash
docker compose -f BE/docker-compose.yml --env-file BE/.env down
```

PostgreSQL 데이터까지 초기화하려면 `down -v`를 사용합니다. 이 명령은 로컬 데이터베이스 볼륨을 삭제합니다.

## 6. 프론트엔드 실행

새 터미널에서 실행합니다.

```bash
cd FE
cp .env.example .env
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열어 OAuth 로그인 후 기본 프로필과 실제 월별 금융 기록을 입력합니다.

## 7. 실제 데이터 원칙

- 금융 예측에는 사용자가 등록한 실제 월별 기록을 사용합니다.
- `Data/` 저장소에는 승인받은 원천 데이터와 전처리 계약만 보관합니다.
- 청년정책은 `GOV_API`로 호출한 온통청년 Open API 응답을 사용합니다.
- 정책 지원금은 공고 문장에서 자동 추정하지 않습니다. 지급이 확정된 금액만 화면에서 직접 입력해 시뮬레이션에 반영합니다.

## 8. 개별 개발 실행 (선택)

Docker 대신 실행할 경우 PostgreSQL을 먼저 준비하고, 각 명령을 별도 터미널에서 실행합니다.

```bash
cd AI
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
AI_SERVICE_TOKEN=BE와_동일한_값 uvicorn app.main:app --reload --port 8001
```

```bash
cd BE
mvn spring-boot:run
```

이 경우 `BE/.env`의 `AI_SERVICE_URL`을 `http://localhost:8001`로 둡니다.
